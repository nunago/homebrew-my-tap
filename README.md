# Nunago My-tap

## How do I install these formulae?

`brew install nunago/my-tap/<formula>`

Or `brew tap nunago/my-tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nunago/my-tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
